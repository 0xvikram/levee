## What is true today

- A deployment protects one token and one treasury. Several tokens per deployment is on the roadmap, so the Issuer tier's "up to 3 tokens" depends on it.
- Levee runs on Hedera testnet only.
- The code is MIT licensed. You can run it yourself today.

## What it costs on Hedera

Network fees are separate from any Levee fee. Measured on testnet:

| Item | Fee |
|---|---|
| One gated payout with scheduled signing | About 0.18 HBAR |
| One containment (freeze plus wipe and freeze) | About 0.23 HBAR |
| One receipt on HCS | About 0.004 HBAR |
| Watcher heartbeats | One HCS message every 30 s |

Hedera fees are fixed in USD, so the cost per payout does not swing with the HBAR price.
