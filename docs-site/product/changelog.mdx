All work so far landed on 6 Nov 2026 (IST), on branch `build` of [0xvikram/levee](https://github.com/0xvikram/levee). Commit hashes link the change to the code.

<Update label="6 Nov 2026, evening (2)" description="Demo command centre">
  - Demo runner gains **mint** and **reset** actions (`8175901`).
  - `/live` becomes a one-screen demo command centre. The mint step waits for an unfrozen thief account and shows the supply spike (`495068f`, `775d167`).
  - Demo stepper order is Send, Hack, Unlock, Fake mint, because a mint cannot land in a frozen account (`608b698`).
</Update>

<Update label="6 Nov 2026, evening (1)" description="Scheduled signing, signed requests, partners never wiped">
  - **Normal sends are Hedera Scheduled Transactions with two separate signers.** The gate schedules with its key and writes the receipt. A separate issuer signer adds the second signature only after it finds the receipt on Hedera (`eb6a4ad`, `2483ced`, `a280c0b`).
  - ContainmentController source verified on HashScan, full match (`31ce848`).
  - **Every gate request is signed** by the requesting machine's own key. `/enrol` is locked with a per-run token (`e110c2a`, `7560843`).
  - **Live unauthorised-mint attack**: 5,000 RUPC minted with a stolen key, wiped and frozen in 7.53 s (`91d30c2`).
  - **The watcher never wipes a known partner.** It freezes it and lets admins decide (`3c9bb93`).
  - Levee positioned for one buyer: stablecoin issuers on Hedera (`b7473fe`, `1157a0e`).
</Update>

<Update label="6 Nov 2026, morning (2)" description="Detection fix, docs, hosted dashboard">

  - Read-only probe of the Mirror gRPC stream against fresh REST reads (`37269b4`).
  - Hosted dashboard on Vercel with a chain mode for `/live` (`69b7e72`).

  - README, Hedera friction log, business one-pager, live run record (`e3b338e`, `4853307`, `212ded0`, `874abec`).
</Update>
