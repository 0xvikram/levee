The ContainmentController splits actions into two kinds.

| Close actions | Open actions |
|---|---|
| Freeze, wipe and freeze, burn, pause | Unfreeze, unpause, change the watcher |
| The watcher or any admin can call them | Need 2 of 3 admins to approve the same proposal |

## How a reopen works

1. One admin calls `propose(action, target)`. This counts as their approval.
2. A second, different admin calls `approve(id)`.
3. At two approvals the proposal executes in the same transaction. For `Unfreeze`, the contract calls the Studio token's `unfreeze(target)`.

A repeat approval by the same admin reverts with `AlreadyApproved`. Approving an executed proposal reverts with `AlreadyExecuted`.

The three actions are `Unfreeze` (0), `Unpause` (1) and `SetWatcher` (2).

## In the demo

```bash
npx tsx scripts/reopen.ts treasury attacker
```

Admin 1 proposes, admin 2 approves and the approval executes the unfreeze. Accounts that are not frozen are skipped. `scripts/demo/reset.ts` also unpauses the token first, if it is paused.

## Limits

- Admins are set when the contract is deployed. They cannot be changed afterwards.
- Two admins acting together can reopen anything and replace the watcher. Levee does not protect against 2 of 3 admins colluding.
